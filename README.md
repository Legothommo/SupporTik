# SupporTik 🚀

**SupporTik** — компактный десктоп-помощник для Windows (WPF/C#) для автоматизации рутинной работы с текстом: мгновенная вставка шаблонов по горячим клавишам, маскирование чувствительных (NDA) данных, удобная организация биндов и просмотр рекламных кампаний Яндекс.Бизнес — прямо из системного трея.

---

## ✨ Основные возможности

* ⚡ **Глобальные горячие клавиши с приоритетом.** Хоткеи перехватываются через низкоуровневый хук клавиатуры, а не стандартный `RegisterHotKey` — SupporTik получает нажатие раньше сторонних программ и побеждает при совпадении сочетаний. Хук корректно отличает реальные нажатия от собственных синтетических (имитация Ctrl+V при вставке), поэтому бинд, назначенный прямо на Ctrl+V, не глотает сам себя.
* 📁 **Папки шаблонов.** Несколько шаблонов можно повесить на одно и то же сочетание клавиш — они группируются в один блок с общим хоткеем, а папке можно задать своё название.
* 🪟 **Быстрое меню выбора.** Если на сочетании клавиш несколько шаблонов, при нажатии появляется всплывающее меню рядом с курсором — с названием папки и списком вариантов.
* 🛡️ **NDA Masking (замена выделения).** Отдельный хоткей маскирует выделенный текст звёздочками прямо во внешнем приложении, не трогая буфер обмена пользователя.
* 📊 **Меню рекламы.** Отдельное окно (доступно и по хоткею, и из меню в трее): поиск рекламных кампаний Яндекс.Бизнес по UID пользователя, фильтры по статусу/роли/апсейлу, ленивая проверка апсейлов сразу после поиска, копирование пермалинков и готовых текстов предложений по выбранным кампаниям. Поиск, проверка апсейлов и расчёт стоимости продления идут параллельными запросами, а не по одному — на больших списках кампаний это в разы быстрее.
* ✏️ **Инлайн-редактирование.** Название, текст шаблона и сочетание клавиш меняются прямо в карточке — без отдельного окна, в том числе у каждого шаблона внутри папки по отдельности; окно создания используется только для новых биндов.
* 📥 **Импорт и экспорт.** Бинды, папки и настройки переносятся одним `.json`-файлом — удобно при переустановке или переносе на другой компьютер.
* 🐾 **Минутка отдыха.** Случайный котик из CATAAS на странице «О программе», с таймаутом и повтором при сетевых сбоях.
* ⚙️ **Гибкие настройки.** Автозапуск через реестр Windows, сворачивание в трей (закрытие через панель задач или Alt+F4 тоже корректно сворачивает, а не роняет окно), запуск в свёрнутом виде, отдельные хоткеи для NDA-замены и меню рекламы, выбор стороны выезда меню рекламы (слева/справа).
* 🎨 **Современный интерфейс.** Fluent-дизайн на базе WPF-UI, переключение светлой и тёмной темы.

---

## 🛠️ Технологический стек

* **Платформа:** .NET Framework 4.8 / WPF (C#)
* **Библиотеки:**
  * `WPF-UI` — Fluent-контролы и оформление в стиле Windows 11.
  * `Microsoft.Web.WebView2` — встроенный браузер для авторизации в Яндекс.Бизнес.
  * `InputSimulator` — симуляция нажатий клавиш при автовставке.
  * `Hardcodet.NotifyIcon.Wpf` — иконка и меню в системном трее.
  * `Newtonsoft.Json` — хранение биндов, папок и настроек.

## 🚀 Быстрый запуск

1. Скачайте архив [SupporTik_v2.3.0.zip](https://github.com/Legothommo/SupporTik/releases/download/2.3.0/SupporTik_v2.3.0.zip).
2. Распакуйте его в любую удобную папку.
3. Запустите `SupporTik.exe`.

> Для работы «Меню рекламы» на компьютере должен быть установлен [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) — на большинстве Windows 10/11 он уже есть системно.
