# SupporTik 🚀

**SupporTik** — компактный и производительный десктоп-помощник для Windows (WPF/C#), созданный для автоматизации рутинной работы с текстом, маскирования чувствительных (NDA) данных и быстрой вставки шаблонов по горячим клавишам.

![SupporTik Preview](https://via.placeholder.com/800x450?text=SupporTik+Screenshot) <!-- Замените на реальный скриншот программы! -->

---

## ✨ Основные возможности

* ⚡ **Глобальные горячие клавиши (Hotkeys):** Мгновенная вставка заготовленных текстовых шаблонов в любое активное приложение.
* 🛡️ **NDA Masking (Замена выделения):** Автоматическое маскирование выделенного текста прямо в внешних программах.
* 📥 **Импорт и Экспорт:** Быстрый обмен конфигурациями биндов через `.json`.
* 🐾 **Минутка отдыха:** Интеграция с REST API (CATAAS) для поднимающих настроение котиков.
* ⚙️ **Гибкие настройки:** Автозапуск через реестр Windows, сворачивание в трей и DPI-Awareness адаптация интерфейса.

---

## 🛠️ Технологический стек

* **Платформа:** .NET / WPF (C#)
* **Библиотеки:** 
  * `InputSimulator` & `NHotkey` — перехват вводных данных и симуляция нажатий.
  * `Hardcodet.NotifyIcon.Wpf` — кастомное меню в системном трее.
  * `Newtonsoft.Json` — управление локальным хранилищем.
